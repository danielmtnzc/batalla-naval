# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

"Batalla naval" (hundir la flota) en el navegador: contra el ordenador o online contra otra persona (Firebase Realtime Database). HTML, CSS y JavaScript puros con módulos ES, sin build ni dependencias; se publica con GitHub Pages. Todo el texto, nombres y comentarios están en español; mantenlo así.

Lee solo las secciones que necesites:

- [docs/claude/comandos.md](docs/claude/comandos.md) — tests, servidor local, despliegue de reglas de Firebase.
- [docs/claude/arquitectura.md](docs/claude/arquitectura.md) — módulos, dependencias entre ellos y reglas del juego.
- [docs/claude/ia.md](docs/claude/ia.md) — el rival controlado por el ordenador y sus tres dificultades.
- [docs/claude/online.md](docs/claude/online.md) — modo online: estructura de la sala, protocolo de disparo, límites anti-trampas y tests con red simulada.
- [docs/claude/firebase.md](docs/claude/firebase.md) — proyecto de Firebase, cuenta, configuración y pasos de consola.
